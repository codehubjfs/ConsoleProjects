# Hotel Management System

## Introduction

The Hotel Management System is designed to streamline and automate various operations within a hotel. This system provides comprehensive tools for hotel staff to manage reservations, allocate rooms, handle billing, and deliver exceptional customer service. By integrating these functionalities into a single platform, the system aims to improve efficiency and enhance the overall guest experience.

## Features

### 1. Administrator
- **Login**: Secure access to the administrator's dashboard.
- **Reservation Management**: Efficiently manage room reservations, including creating, modifying, and canceling bookings.

### 2. Front Desk Staff
- **Login**: Access to the front desk interface to manage guest interactions and room assignments.
- **Reservation Handling**: Facilitate check-in and check-out processes, allocate rooms, and respond to guest inquiries.
- **Billing and Payment Processing**: Generate bills, process payments, and issue receipts.

### 3. Housekeeping Staff
- **Login**: Secure access to the housekeeping interface for managing room cleanliness and maintenance.
- **Room Cleaning Management**: View current room statuses, assign cleaning tasks, and track the progress of room maintenance.

### 4. Guest
- **Reservation**: Book rooms online, modify existing reservations, and cancel bookings if needed.
- **Check-in/Check-out**: Efficiently complete check-in and check-out procedures.

## Technologies Used

- **Java 8 or Higher**: The programming language used for developing the application.
- **Spring Framework**: Provides comprehensive infrastructure support for developing Java applications, including Spring MVC for web application development.
- **MyBatis**: A persistence framework that simplifies database interactions and supports mapping SQL databases to Java objects.
- **Oracle Database**: Used for storing application data and managing database operations.
- **Maven**: A build automation tool used for managing project dependencies and building the project.
- **JSP (JavaServer Pages)**: For rendering dynamic web pages.
- **Servlets**: Java classes used for handling HTTP requests and responses.
- **Bootstrap**: Frontend framework used for designing and styling the web application.

## Prerequisites

- **Java 8 or Higher**: Ensure that Java Development Kit (JDK) 8 or later is installed.
- **Maven**: Required for project build and dependency management. Download and install Maven from the [Apache Maven website].
- **Spring Framework**: For setting up the application context and handling web requests.
- **MyBatis**: To handle data persistence and database interactions.
- **Oracle Database**: Set up an Oracle Database instance for storing and managing data. Configure database connection settings in the project as required.
- **IDE (Integrated Development Environment)**: Recommended IDEs include IntelliJ IDEA, Eclipse, or any other Java-compatible IDE for development.
