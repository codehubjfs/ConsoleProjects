# Task Management Application - Spring MVC Version

## Introduction
This Task Management application is developed using Java, Spring MVC, Maven, Oracle JDBC, and MyBatis.

## Features

### For Employees
- Create and manage personal tasks
- Search for assigned tasks based on deadlines
- Update task status
- View and manage their profile

### For Managers
- Create and assign tasks
- Search for employees
- View and manage their profile
- Create and manage personal tasks

### For Admins
- Manage user accounts
- Monitor performance
- Add new employees and managers
- Add new admins

## Technologies Used
- Java
- Maven
- Oracle Database
- JDBC
- MyBatis
- Spring MVC
- JSP
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

## Prerequisites
Before you begin, ensure you have the following installed on your machine:
- Java 8 or higher
- Maven
- Oracle Database
- IDE (Eclipse, IntelliJ, etc.)

## Getting Started

1. Clone the repository:
   \`\`\`bash
   git clone https://github.com/yourusername/TaskManagementApplication.git
   \`\`\`
2. Navigate to the Spring MVC version directory:
   \`\`\`bash
   cd TaskManagementApplication/SpringMVCVersion
   \`\`\`
3. Open the project in your IDE.
4. Update the \`application.properties\` file with your Oracle DB credentials.
5. Build and run the project using your IDE or deploy to a servlet container (Tomcat).
